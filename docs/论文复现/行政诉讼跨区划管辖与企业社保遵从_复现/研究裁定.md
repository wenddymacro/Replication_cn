## 日期恢复与单期观测

1. 公开企业数据有26604行，其中9行缺少必要ID/年份；作者主回归实际样本为26595行、3015家企业、246个城市。有效面板年份为2008–2021，论文描述初始选取2007–2021并使用滞后控制。附件是处理后的回归数据，不再擅自将控制变量滞后一次。
2. 企业城市归属恒定，city-year的court一致，处理没有1→0关闭。不能把不平衡企业进入样本时第一次看到court=1的年份误当政策日期。
3. 用作者pre6…pre1、current、post1…post5的精确相对期，计算城市政策年=年份−相对期；同一城市所有此类推算必须一致。由此恢复真实可辨认年份，包括样本前改革和2022年才改革的城市；后者在本样本内尚未处理。
4. cityid=51在2008年起只有posta>=6尾箱，不能恢复确切日期。用2002上界作为静态分类哨兵，对所有2008–2021设定都映射为“一直处理”。不是声称该城市恰在2002年改革。未开展依赖这一确切日期的现代事件路径。
5. cityid=145、256各只有2021年的一个企业观测，均为已处理且只有尾箱，无法恢复精确日期。不能凭此捏造2015或2021为政策年；本轮共同现代输入剔除这2行，企业设定输入26593。是明确的本轮裁定，不是上游强制预处理。城市机制回归的作者样本不含这两行，保持原作者样本。样本差异单列，原模型仍先用作者完整样本核对。没有借用案件数据的cityid去填企业数据日期，避免假定匿名ID跨文件或处理口径一致。
6. 保留其余作者单期企业观察；上游fixest TWFE实际回归可能自动删除单期FE观察，而n列按prep_data输入统计。另导出TWFE实际nobs供审阅。BJS按上游删除无可识别未处理固定效应的行，输出中保留bjs_nonimputable_dropped。CSA按did处理一直处理单位；三法共同输入不等于有效估计样本完全相同。

## 控制、推断与实施差异

静态9项各999次联合聚类贝叶斯自助，种子1；CSA/did自身乘子自助按上游999次。对带控制项设定，联合自助仅重算TWFE/BJS，不声称已有TWFE–CSA联合协方差。上游analysis的控制CSA协方差按0处理。控制模型现代估计量杠杆未实现时为twfe_only，不能说通过双方杠杆规则。

保留一个已知上游差异：PROTOCOL文字要求CSA使用g−1控制值，但原代码对不平衡面板使用allow_unbalanced_panel=TRUE；[did官方说明](https://bcallaway11.github.io/did/reference/DIDparams.html)表示不平衡路径使用各期协变量。代码原样保留，相关结果标明此差异，不能声称已经实现文字中的基期控制规则；需要老师统一规则后再决定正式项目汇总口径。

G_eff>=10且L_max<=0.25是比较的杠杆要求；得到点估计和SE不等于通过此规则，也不等于识别假设已验证。报告明确区分原作者精确复现、现代点估计/SE可用和杠杆筛选情况。
