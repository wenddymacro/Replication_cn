## 资料限制

作者随附件说明：受土地出让微观数据管理要求限制，只公开随机抽取的4%样本供验证。附件包括数据、Stata程序、附录和数据使用说明。故此处所有估计都只能核验公开样本，不能代表原始全样本复现。

公开原始数据有35,236条记录；依作者程序剔除非住宅/工业/商业用途后，作者基准筛选回归的 `e(sample)` 为29,433条。原文表1第(2)列全样本结果为0.0868，标准误0.0432，N=735,620；作者程序在公开4%样本复算该列为0.1803，标准误0.0599，N=29,433。抽样复算与全样本数值不一致，符合数据范围差异，不能据此判断程序错误。
