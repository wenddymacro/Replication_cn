# 减税与企业工业机器人应用：复现审计

## 文章与资料

- 论文：刘学悦、赵城、寇宗来，《减税与企业工业机器人应用》，《中国工业经济》2025年第7期，81–99页。
- 作者附件含：Stata `.do` 程序、附录PDF、数据使用说明、表格RTF结果、若干用于绘图的 `.dta` 中间数据。
- 附件中未找到主回归样本 `数据/tax_robot.dta`。作者程序开头即从该路径读取数据；缺少此文件，主回归及作者程序无法运行。
- 论文说明使用2004—2012年中国工业企业数据库与海关数据库的匹配数据。这些不是随ZIP提供的开放数据。作者附件也没有发现生成主样本的完整清洗/匹配程序。

## 设计筛选（老师项目规范）

- 政策：2008年“两税合一”企业所得税改革。
- 处理组：受益的境内民营企业（POE）；对照组：外资企业；政策后期：2008年及以后。
- 基准模型：企业固定效应、年份固定效应，并逐步加入行业×年份、城市×年份及企业事前特征×年份固定效应；按企业聚类。
- 这是单一政策时点的两组DID（binary treatment），适用于作者TWFE基准复核。它不是交错处理设计，因此不纳入老师协议中面向多批次处理的CSA/BJS主分析，也不对单一共同处理时点强行套用这些估计量。
- 事件研究用于平行趋势诊断；异质性三重交互项按项目筛选规则不作为独立的处理效应设定。
