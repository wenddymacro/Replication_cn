## 识别设计与数据结构审计

数据2有 8,251 条并购事件，年份为 2007—2021，处理批次变量 `postyear` 覆盖 2012、2014—2021，另有从未处理组（3000）。处理赋值对应并购标的城市 `UnderlyingCity`，作者回归却在并购交易层面估计，并吸收买方证券代码固定效应。一个证券代码—年份存在多笔交易，因此这不是标准的公司—年份面板。直接把每笔交易当作单位套用以城市为组的现代 DID，会产生单位和推断层级不一致的问题。

当前已核实作者环境依赖；机器中没有 `csdid`、`did2s` 或 `did_imputation`。现有 `did_multipleGT` 是另一类多组多期 DID 工具，不等同于 Callaway–Sant’Anna 或 BJS。由于原始因变量是交易事件层面、政策单位是标的城市，尚未把未经论文定义的城市—年聚合结果冒充为原设定的现代 DID 估计。因此 CSA、BJS/did2s 和 999 次联合 bootstrap 尚未完成，当前不能标注为满足项目全部现代估计要求的完整复现。
