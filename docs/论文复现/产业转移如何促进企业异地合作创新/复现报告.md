# 复现报告：产业转移如何促进企业异地合作创新

## 摘要

本文按项目冻结协议复现《中国工业经济》2026年第6期《产业转移如何促进企业异地合作创新——基于产业链供应链优化视角》。附件数据和代码可用。作者正文表1六列、表5八个结果均由等价 TWFE 核对到印刷精度（表1第3、6列的 t 值只在最末一位有不足 0.00015 的差异）。在协议要求的无时变控制变量主规格中，以“企业首次实际暴露年”重建吸收处理并删除1条处理后关闭观测后，TWFE、CSA、BJS 的标准化处理效应均为正；但有效聚类数未达到10，且 CSA/BJS 最大聚类杠杆超过0.25。因此这篇论文的现代估计比较未通过项目杠杆筛选，不能据此做可靠的显著差异判断。

## 1. 论文与识别设计

- 作者：戴宏伟、乔莹莹、贺茜。
- 政策：国家级承接产业转移示范区分批获批，政策批次为2010—2014年。
- 数据：沪深 A 股企业—年份，2007—2021年；附件分析数据 16,499 行、2,849 家企业、203 个城市。
- 被解释变量：合作创新申请的 `lnapp` 与 `ihs_cro_app`。
- 作者正文表1：企业与年份固定效应，城市聚类；第(1)、(4)列无控制变量，第(2)、(5)列含时变控制变量，第(3)、(6)列含基期特征与年份交互。
- 按项目协议，只有表1第(1)、(4)列属于主合格设定。第(2)、(5)列及表5八个含时变控制变量设定列入控制变量次级结果；表1第(3)、(6)列的连续基期特征×年份线性项不等同于协议允许的类别×年份固定效应，故仅做作者数值核对，不送入冻结估计器。

## 2. 数据核查与处理裁定

附件回归数据有38家企业发生城市迁移、4家企业的 `approval` 随时间变化。附件逐行 `did` 与当期所在城市的批准时间一致。若简单按企业最早 `approval` 定 cohort，会把17行提前归为处理，故正式规格不采用该方法，而以企业首次观察到 `did=1` 的年份确定首次暴露年。企业迁址后有1行 `did` 从1回到0；遵循项目协议，剔除该处理后关闭行。正式处理样本由此为15,996行；含控制变量的共同样本为15,578行。正式样本包含12个企业首次暴露 cohort，时间范围仍是2007—2021年。面板不平衡，只有37家企业有完整15年记录。

CSA 需要稳定的聚类标识；因原始城市聚类会随企业迁址而变化，正式现代估计采用企业首期城市作为稳定聚类。作者结果核对仍保留作者的当期城市聚类。此差异属于协议适配，不能把现代估计标准误与作者表中 t 值直接等同。原始附件未修改；所有变换都在派生数据副本完成。

## 3. 作者结果核对

等价 TWFE 对正文表1六列及表5八个结果重新估计。14项的系数和 N 均与印刷值匹配至4位小数；表1第(3)、(6)列计算 t 值分别为2.057149、2.097266，论文印刷为2.0570、2.0972，最末位存在小于0.00015的数值差异。表1括号内是 t 值，不是标准误。

逐项记录见 [`output/author_source_checks.csv`](output/author_source_checks.csv)。这里使用 R `fixest::feols` 等价实现；未用 Stata 直接运行作者 `.do` 文件。原作者程序没有显式载入回归数据的命令，且其平行趋势数据文件名与 ZIP 内文件名不同，所以报告的是等价估计而非声称原 `.do` 可原样直接运行。

## 4. 协议主样本：TWFE、CSA、BJS

因三个估计量以同一正式样本中的因变量标准差标准化，结果单位为因变量标准差。标准误为各方法对应的聚类标准误；`BSD` 列是999次联合聚类贝叶斯自助法的标准差估计。

| 规格（表1） | 作者系数 | 正式样本 TWFE（标准化） | CSA | BJS | G_eff（TWFE/CSA/BJS） | 最大杠杆（TWFE/CSA/BJS） | 诊断 |
|---|---:|---:|---:|---:|---|---|---|
| (1) lnapp | 0.2625 | 0.3567 (SE 0.1344；BSD 0.1395) | 0.1511 (SE 0.0830；BSD 0.0848) | 0.2510 (SE 0.1062；BSD 0.1096) | 6.77 / 3.50 / 3.66 | 0.226 / 0.432 / 0.420 | 三种方法 G_eff 均<10；CSA、BJS 最大杠杆>0.25 |
| (4) ihs_cro_app | 0.3292 | 0.3645 (SE 0.1356；BSD 0.1412) | 0.1529 (SE 0.0852；BSD 0.0850) | 0.2571 (SE 0.1057；BSD 0.1095) | 6.77 / 3.50 / 3.66 | 0.226 / 0.432 / 0.420 | 三种方法 G_eff 均<10；CSA、BJS 最大杠杆>0.25 |

基于自助协方差，表1(1) TWFE−CSA 差为0.2055（SE 0.1589，z=1.294），TWFE−BJS 差为0.1057（SE 0.0721，z=1.466）；表1(4)两项差分别为0.2116（SE 0.1631，z=1.297）与0.1075（SE 0.0744，z=1.445）。两项差异均未达到常用双侧5%显著水平；且杠杆筛选未通过，推断应谨慎。

主样本负权重诊断：处理观测中约42.02%对应负权重；负权重绝对值占比约1.27%。三个点估计均为正，方向一致；TWFE 点估计大于 CSA 与 BJS。由于两个主规格都未通过有效聚类数门槛，CSA/BJS 的最大杠杆也超过门槛，项目协议要求的杠杆筛选不通过，不能把点估计差异解释成已证实的稳健显著变化。核心估计器按项目冻结版本运行，没有为本篇修改。

未控制规格的 CSA 标记43个空的 cohort×时间格，并按不平衡面板继续估计。`did` 包在以城市为单位聚类时不提供解析 Wald 前趋势预检；日志提示使用 bootstrap 区间评估前趋势。BJS 对不可插补的处理观测作可用性剔除：无控制主规格各剔除558条，控制变量规格各剔除545条。以上信息随原始输出保留在 `output/modern/`。

## 6. 可重跑与完整性

1. `code/verify_package.ps1` 对原 ZIP 做 CRC 检查并生成附件文件 SHA-256 清单 `data/source_manifest.csv`。
2. `code/replicate_authors_baselines.R` 重跑作者正文表格等价 TWFE 对照。
3. `code/prepare_data.R` 从作者回归数据生成正式分析数据和样本审计。
4. `code/run_all_modern.ps1` 重跑12个正式/次级规格；运行状态见 `output/modern/run_status.csv`，12项 `exit_code=0`。每项自助法 B=999。
5. 冻结核心 `code/R/estimators.R` 与 `code/R/run_spec.R` 与 `reference/Replication_cn-main/code/R/` 对应文件 SHA-256 一致；本地完整性校验在归档前重跑。

## 7. 范围和未复现内容

该篇的项目主任务是论文正文合格交错 DID 规格的三估计量比较；已覆盖表1无控制变量两列，并额外运行控制变量次级样本。作者表2—表4为异质性分组/机制分析；表1第(3)、(6)列为连续基期特征×年份；泊松、PSM-DID、替换聚类等为不同方法/稳健性规格，不属于冻结协议的正文合格 DID 主规格。作者附录报告的 `csdid`/事件图没有在 Stata 中逐项原样运行；附件预先提供的平行趋势估计数据已核对变量和事件期，但本次未将其作为主规格重新估计。因此本报告不声称复现了所有正文与附录的所有模型，而是完成项目协议下主规格及列明的近似规格。
