## 重跑

在 Windows PowerShell 中，从本目录运行：

```powershell
Rscript code/replicate_authors_baselines.R
Rscript code/prepare_data.R
pwsh -File code/run_all_modern.ps1
```

`run_all_modern.ps1` 使用项目冻结的 R 核心估计脚本和本机已安装的 R 包；自助法次数为 999。所有路径应按脚本要求在本机配置。输出位于 `output/`。
