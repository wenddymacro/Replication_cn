## 结论：有数据代码，但不符合老师交错DID项目

附件含8份可读取的Stata数据、7份Stata/Python程序、作者主要回归日志和附录。本次完成的是资料接收、分类、完整性检查及入选筛选；**没有运行作者回归，不把作者日志当成本次独立复现结果。**

按老师[Replication_cn](https://github.com/wenddymacro/Replication_cn)的SCREENING.md第1步，只有一个政策时点的两组DID不是交错设计，eligible_design=false。该文因此不纳入TWFE/CSA/BJS交错DID重估样本，也不纳入“仅因时变控制变量”二级样本。

具体证据：

- 正文表1第1–2列以连续指标SIM（企业国际标准技术对接强度）为核心解释变量；其他主要结果同样围绕连续强度及其交互项展开，不能把其多年变化视为二元交错处理。
- 表1第3–4列为Bartik工具变量一阶段和2SLS，不是合格的二元TWFE设定。
- 表1第5列DID将2015年《深化标准化工作改革方案》作为统一政策冲击，按企业政策前三年对接强度在行业内的相对水平划分高低暴露组；这并非不同企业在不同日历年采纳政策。
- 正文PDF第12页（期刊130页）和附录6明确说明该统一冲击；已查看正文对应页的渲染图。
- 包内主数据有57,040行、5,233家企业，覆盖2002–2024年。对did=1按id求最早year，927家处理企业全部为2015年，只有1个观测处理批次；无重复id×year、无处理由1退回0。
- 因此不能以“使用了DID”为由将该文算作老师项目的交错DID论文，也不人为改处理年份制造多个批次。此排除不意味着论文不能进行一般意义上的原模型复现。
