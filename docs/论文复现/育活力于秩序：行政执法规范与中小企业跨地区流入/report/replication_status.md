## DID设计与审计

- 单位：县（county_id）；时间：2011—2020年；结果变量：Firmflows（中小企业跨县流入的IHS值）；处理：Discretion（行政裁量权基准制度实施）。
- 数据：2,722个县、27,220个县年观测、328个城市聚类。
- 首次处理时间分批变化：2011年158县（样本开始即处理，无法识别处理前反事实）；2012年178、2013年101、2014年58、2015年88、2016年62、2017年6、2018年13；从未处理2,058县。无处理后回落记录。
- 该设计满足交错DID基本条件。按老师协议把2011首期已处理县作为always-treated并从现代动态识别中排除；有效处理批次为2012—2018年，共7批，保留从未处理组。
- 作者正文表1第(5)列包含8项时变县控制变量及县FE、省份×年份FE，TWFE结果复跑为0.15999（SE 0.04842）。按照项目协议，主样本现代估计不放时变控制；含控制版本作为 secondary 单独报告。
