## 现代 DID 复现

现代估计均使用 `ln_transaction_freq` 为结果变量，`treat_year` 为首次处理批次，标准误按 IPC4 聚类。运行代码在 `code/modern_did.do` 与 `code/csdid_window.do`，完整结果在 `logs/modern_did.log`、`logs/csdid_window.log`，估计对象保存在 `output/*.ster`。

| 方法 | 估计结果 | 说明 |
|---|---|---|
| Callaway–Sant’Anna (2021) | 事件期 −6 至 +6 的处理后平均效应 0.000964（SE 0.002824，p=0.733） | 999 次 multiplier bootstrap；IPC4 聚类；事件期同时置信带。窗口内各期均不显著。 |
| Borusyak–Jaravel–Spiess (2023) | 事件期 0、1、2 分别为 0.00851、0.00866、0.00648；后续事件期不显著 | 专利和年份固定效应，N=79,285。前置期 1、3、4 显著，平行趋势需要谨慎。部分早期处理观测因无法插补被自动剔除。 |
| Gardner 两阶段 DID | 0.004509（SE 0.001469，p=0.002） | 专利固定效应通过 `unit(pt_id)` 吸收，第一阶段含年份固定效应；4 条缺失观测被剔除。 |

C&S 的全样本组期 ATT 中 1,092 个单元有 324 个因没有合适比较组而无法估计；已按命令支持的 `dropmissing` 对可估计单元做汇总。窗口内结果和同时置信区间见 `output/csdid_event_window.dta`、`logs/csdid_window.log`。估计前检验因协方差矩阵奇异未提供 Wald 统计量；这点也保留在 Stata 输出中。

## 结论与限制

作者 TWFE 与 Gardner 两阶段结果为正且显著；C&S 在 −6 至 +6 事件窗口的平均处理效应不显著；BJS 的近端事件效应为正，但多期处理前系数显著。修正后的 Sun–Abraham 前置项不显著。不同估计器在事件时间、可用比较组和固定效应处理上对应不同加权目标，因此不能将这些结果压缩成“所有现代 DID 都确认正效应”。尤其 BJS 的前置系数使平行趋势假设需要谨慎评估。

Gardner 两阶段命令使用 `unit(pt_id)` 与年份固定效应，未将约 7,000 个 IPC×年份类别展开为虚拟变量；作者的 IPC×年份规格已由作者 TWFE、C&S/BJS 对应设定保留。该选择避免普通虚拟变量回归矩阵过大，并在本机成功运行。

本包保留了数据、作者原件、路径修正副本、复现脚本、日志、估计文件和图形，当前复现流程已执行完毕。所有结果均来自作者公开数据；未使用额外原始数据重建。
