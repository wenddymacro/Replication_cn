# 共同富裕进程中的数字政府建设｜复现与筛选

《中国工业经济》2026 年第 6 期。使用用户提供的作者附件。归档包含三份分析数据、作者命令和附录。

## 原文复算

用 R fixest 等价重算公开命令中的 133 条 OLS／固定效应／IV 回归，输出全部系数、标准误及 N。作者命令使用 Stata 变量缩写 dmerge，R 中将其显式映射到数据中的唯一匹配 dmerger。

正文表 3 五列系数和 N 全部匹配，四个 OLS 标准误匹配四位小数。2SLS 系数 −0.5374，N=1669；复算标准误 0.2054，发表值 0.2053。附表 16 两列的系数、标准误和样本量均匹配，分别为 −0.0309（0.0081）及 −0.0110（0.0053），N 均为 3738。其余表图未逐项对照印刷值，IV 第一阶段诊断、图形和描述统计未逐项核验。

## 老师项目筛选

正文核心解释变量是连续的数字政府发展指数 digit_gov。城市附件的 1,670 条记录有 1,670 个不同指数值。正文主模型不具备二元交错处理，IV 规格也不符合项目正文纳入规则。主样本 0 项，二级样本 0 项。

附表 16 的信息惠民试点 did2 为单一 2014 年批次。政务微信公众号 did3 有 2013–2022 年十个处理批次、13 个从未处理城市，观察中无处理回落。它出现在附录政策冲击检验，已按作者原式复算，未纳入正文 TWFE、CSA、BJS 比较。
