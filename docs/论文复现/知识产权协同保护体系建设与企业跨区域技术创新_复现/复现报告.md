# 知识产权协同保护体系建设与企业跨区域技术创新

韩先锋、郑酌基，《中国工业经济》2025年第12期。期刊论文编号 cie121822。使用作者官网附件中的数据与程序。按老师的 Replication_cn 协议逐设定筛选。

## 样本裁定

- 表1及表3至表6为非线性 PPML。表1按原 PPML 方程检验原文数值，线性 DID 主样本和二级样本均不收录这些列。
- 表2 A栏第1至3列是城市与年份双固定效应线性回归，唯一的设定排除项是 GDP、人口、产业结构等时变控制变量，进入二级样本。城市面板有 3,151 行、294 个城市，城市×年键唯一。37 个城市首次处理分布在 2018–2022 年五个批次（6、6、3、9、13），样本中无从处理转回未处理的城市。
- 表2剩余六列均有时变控制变量，额外的可加行业及地区固定效应在作者估计样本中也确实随 id 变化。六列均按原式复算，但不纳入仅时变控制的二级样本。主数据 433,628 行中，以公布的 id×year 计有 402,319 行重复键，不能直接把该 id 解释为唯一公司对面板键。
- 附表6的 CSDID 和负权重检验登记为附录设定。未对公布数据中重复的 id×year 猜测或重新构造公司对键。

## 表1原文复算

以 fixest 的高维固定效应 PPML 重跑作者基准表。10列的处理系数均与原文四位小数一致，样本量也逐列一致。聚类标准误均略高，最大相对差约 0.38%。例如 A栏第4列为 0.3755（标准误 0.1734，253,568 行），作者报告 0.3755（标准误 0.1727）。本次使用 R 的 fixest 和作者相同的城市×年份聚类，未核实差异具体来自哪项 Stata 与 R 的推断实现。该表的结论标记为近似复算。逐列对照见 output/table1_printed_comparison.csv。

## 表2原文复算

用 fixest 复算。表2九列的处理系数、聚类标准误（四位小数）及样本量全部与原文一致。A栏前三列依次为 0.0615（0.0209，3151）、1.2028（0.5708，3151）、0.0897（0.0210，2745）。六列公司样本结果见 output/table2_pairs.csv。

## 二级样本重估

保留原文城市×年聚类时，三个结果的 TWFE 和 BJS 系数均为正。项目的 did 包拒绝在面板中使用随时间变化的聚类变量，三个 CSA 均留空。重估结果采用因变量标准差为单位。联合贝叶斯自助法为 TWFE–BJS 运行 999 次，二级样本当前实现没有 CSA 联合协方差和 CSA/BJS 的杠杆指标。三个设定 TWFE 负权重份额均为零。按联合自助方差和协方差计算，三项 BJS−TWFE 差异的配对 z 值约为 −0.01、0.47、−0.03，均未达到 5% 双侧显著水平。

另报按城市聚类的敏感性分析。样本对齐到各列原 TWFE 估计样本，并保留原模型控制变量。TWFE 和 BJS 的控制变量按项目代码处理，CSA 使用处理前基期信息。城市聚类改变推断口径。

## 文件
