# 范围、缺口和使用说明

## 当前范围

目标是《中国工业经济》全部已刊年份中实际使用DID的实证论文。本轮不是按单一题名关键词直接确认论文：题名候选、摘要/方法线索、原文证据、数据取得、实际运行分别记录。

2017—2024年已有每年12期题录索引，但尚未逐篇读完全文。2025年原有1—7、9期索引，新补10—12期转载题录以及8期的3条方法线索，8期全目录仍需补齐。2026年补得1、2、4、6、7、8、9期的部分转载题录；3、5、10期及截至核验日其他已发行期次尚未完整核对，7期有一篇综述未进入现有题录。2015、2016年仅补得少量明确线索，早于2015年的完整逐期目录尚未建立。这些年份绝不能按“0篇DID”报告。

## 为什么不能称为全部

期刊官网部分页面返回403/人机验证，部分历史PDF和附件入口失效或无法读取。其他公开摘要目录也有缺期、图片标题和转载错漏。对全部历史论文做完全文筛查之前，任何当前篇数都只表示已找到的条目数，不能当作期刊全部DID论文总数。已核附件的可复现性又是独立步骤，不能由期刊的数据公开政策直接推断。

## 三份清单分别怎么用

1. `中国工业经济_DID论文名单_阶段核验版.csv`：先按证据等级A、B、C及准备顺序找原文和数据。C中的命令线索不等于原文已核实；所有非链长制条目的数据代码仍需核验。
2. `DID待核候选_题名线索不是确认名单.csv`：用于补漏，不能把其中论文直接统计为DID，更不能统计为可复现论文。
3. `全部已收集题录_方法核验台账.csv`：保留所有现有题录，未查明的条目写“未完成全文方法核验”，不因题名没有DID就排除。

CSV使用UTF-8 BOM，可用Excel打开。原文入口、附件入口、官网目录和方法证据分别列出。链接是线索，下载时应核对PDF首页题名、作者、期次与压缩包README，避免转载错误配对。只有压缩包中有实际可用分析数据、程序和必要依赖，且运行结果可核对，才可升级为可复现状态。

## 与老师项目的关系

本名单是广义DID检索层。老师项目的交错DID主样本还需要独立筛查，尤其要区分同一政策时点与分批处理、正文基准与附加稳健性、无时变控制与作者含控制的原规格。不把一次原设定复现等同于完成现代估计量重估。

链长制论文已另行交付原设定核对与老师协议重估报告；公开税调样本不可得及随机检验差异等限制以原报告为准。智慧城市论文已读原文，基准单时点DID，数据尚未取得。金融开放、货币政策与企业出口不属于本次DID名单。

本轮另尝试逐项读取2017—2019年索引中的367个PDF入口，其中349个读取失败。其余PDF的文本提取存在乱码/未命中问题；没有把这些失败或未命中记录当成“非DID”。逐项日志留存在工作目录。
